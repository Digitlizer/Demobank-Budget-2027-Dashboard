Demo Bank: Budget 2027 Dashboard

Power BIView code on GitHub

A bank-wide budget dashboard for top management: flip KPI cards with commentary, a group menu, compare-to buttons, profit bridge, segment scorecard, balance sheet and a 2026 tracker. Demo Bank is fictional and all figures are randomly generated.

What it does

Flip KPI cards

Click a card to read the commentary on the back.

Group menu

Bank-wide and 8 groups. One click focuses every visual.

Compare to

Budget 2027 against Projected Dec-26, Budget 2026 or Actual Dec-25.

Group input workbooks

Each group fills its own Excel file. Power BI merges them on refresh.
